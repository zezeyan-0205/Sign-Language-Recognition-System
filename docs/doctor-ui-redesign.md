# 医生端电子病历工作台 UI 优化说明

## 目标

医生端保持“左侧病历区 + 右侧监控区”的业务结构，同时加入更清晰的门诊电子病历工作台层级。整体回归蓝、白、灰医疗工作站风格，只保留克制的悬浮分层，避免过强车载座舱感。

## 主要改动

### 0. 左侧固定导航栏

- 医生端由单页窗口改为“左侧固定窄导航 + 右侧页面容器”的水平分栏结构。
- 左侧导航栏固定宽度，深灰近黑背景，顶部为医生头像，下方为 7 个单色 SVG 线性图标。
- 当前页面图标为纯白，高亮项保留低亮深灰底；未选中为浅灰，hover 仅做轻微变亮。
- 右侧使用 `QtQuick.Controls` 的 `StackView` 承载页面；首页完整保留门诊手语沟通病历工作台，其余页面先作为轻量业务占位页，后续可继续扩展。

### 1. 顶部通栏

- 新增顶部通栏，包含页面标题、系统状态、患者端实时摄像头预览、启动/停止系统按钮、齿轮设置入口和窗口控制按钮。
- 患者预览复用 `CameraView`，由 C++ 控制器同步推送同一帧画面到患者端与医生端，便于医生观察患者动作是否进入识别区域。
- 齿轮入口常驻右上角，hover 时变为医用青蓝并轻微旋转，点击打开全局设置弹窗。

### 2. 全局设置弹窗

新增 `DoctorSettingsDialog.qml`，分为 5 个分页：

- 手语识别参数
- 病历模板配置
- 界面显示设置
- 硬件摄像头配置
- 系统通用设置

弹窗目前作为医生端设置面板 UI 壳，保留一键重连入口，后续可继续接入真实参数保存、病历导出和摄像头通道切换。

### 3. 色彩与层级

- 医生端底层背景统一为浅蓝灰 `#eef5fb`，更贴近医院信息工作站。
- 左侧病历区从纯白改为低饱和冷浅灰渐变，减少左右深浅割裂。
- 右侧监控卡片统一改为白/浅蓝灰渐变，提升层级但不使用强发光。
- 状态色统一为浅灰黄、医用青蓝、薄荷绿和低饱和浅红。

### 4. 病历区

- 左侧病历区占 62% 宽度，突出“患者主诉”和“病历记录”。
- 顶部加入新建、保存、导出、清空快捷按钮。
- 主诉、症状、起病时间、当前识别、病历记录统一为柔和浅底卡片。
- 支持将右侧识别词流一键填入病历记录，减少重复录入。

### 5. 监控区

右侧监控面板保留 5 个模块：

- 系统状态
- 实时识别
- 识别词流
- 关键判断
- 运行指标

每个模块增加左上状态指示灯。FPS 与延迟信息增强显示，帧龄过高时延迟文字自动切换为柔和警示黄。

### 6. 异常提示

- 当识别 worker 或摄像头打开失败导致状态变为“错误”时，医生端弹出连接异常提示。
- 弹窗提供“一键重连”和“关闭”按钮，符合门诊演示时快速恢复链路的需求。
