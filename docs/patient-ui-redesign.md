# 患者端 QML 界面医疗科技风格重构说明

## 设计目标

本次重构将患者端界面从纯白扁平控件，调整为“深色座舱科技基底 + 医疗低饱和状态色 + 分层悬浮卡片”的视觉体系。整体参考比亚迪 DiLink 车载 HMI 的分层、圆角、深色基底和触控大按钮，但弱化强高光、霓虹和大面积强对比，避免诊室长期使用时刺眼。

## DiLink 质感转译

- 深色低亮度背景：使用深炭黑基底，降低屏幕炫光，适合诊室大屏和长时间观察。
- 悬浮卡片层级：左侧摄像头、右侧状态、整理结果、识别词、提示区均使用二级卡片承载，形成空间层级。
- 控件圆角统一：模块卡片使用 14px 大圆角，按钮、进度条、状态标签使用 8px 小圆角。
- 细微渐变：按钮和进度条使用克制渐变，只增强质感，不使用霓虹光效。
- 触控大按钮：开始/结束为主要操作，删除/清空为次要操作，视觉权重明确。

## 医疗场景专属调整

- 色彩低饱和：主色使用冷静浅青蓝，成功使用薄荷绿，等待使用米浅黄，异常使用低饱和砖红。
- 状态优先：第一视觉焦点是医患交互状态，而不是装饰元素。
- 文本层级清晰：标题、主状态、辅助说明使用不同字号和透明度，避免患者和医护人员误读。
- 信息克制：底部提示和辅助文字使用浅灰，不抢占核心识别结果。

## 四种业务状态

| 状态 | 视觉主色 | 使用场景 | 页面提示 |
| --- | --- | --- | --- |
| 等待医生启动 | 柔和米浅黄 | 医生端未启动系统 | 请等待医生端启动系统 |
| 识别就绪 | 冷静浅青蓝 | 系统已启动，等待患者点击开始 | 点击开始后把手放入左侧识别框 |
| 采集中 | 冷静浅青蓝 | 正在采集手语动作 | 请保持当前手语动作，等待进度完成 |
| 识别完成 | 低饱和薄荷绿 | 已识别词汇或已生成整理结果 | 结果已生成，可继续表达或清空重来 |

## 新增 QML 组件

- `Theme.qml`：统一维护颜色、圆角、间距、字号和状态映射。
- `MedicalCard.qml`：医疗悬浮卡片，提供柔和边框和顶部弱高光层。
- `MedicalButton.qml`：多状态触控按钮，支持禁用、hover、点击缩放反馈和克制渐变。
- `MedicalProgressBar.qml`：平滑填充的状态色进度条。
- `StatusBanner.qml`：主状态提示卡片，用于显示当前识别状态和核心词汇。
- `StatusPill.qml`：小型状态标签，用于摄像头区域和识别词区域。

## 页面布局

患者端保持左右分栏：

```text
左侧：摄像头实时画面 + 状态标签 + 舒缓等待提示
右侧：主状态卡片 + 整理结果 + 识别词 + 采集进度 + 操作按钮 + 医患提示
```

该布局保留了原有演示流程，同时强化医疗状态辨识度和触控可读性。
